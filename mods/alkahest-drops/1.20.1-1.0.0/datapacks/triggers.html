Triggers

By default a mob drop happens when the mob dies. The on key makes it happen on other events: when a player shears or hits the mob, when lightning strikes it, or every so often while it lives. Mob files only.

onHappens whenPlayerExtra key
deathThe mob dies (default).The killer, if any
shearA player shears it with shears.Yes
hitA player deals damage to it.Yescooldown (ticks, default 0)
lightningLightning strikes it.No
periodicTime passes while it is alive.Nointerval (ticks, default 6000)

20 ticks are one second; 6000 ticks are 5 minutes.

Examples

{
  "version": 1,
  "entity": "minecraft:sheep",
  "drops": [
    {
      "item": "minecraft:string",
      "chance": 0.5,
      "count": { "min": 1, "max": 2 },
      "drop_behavior": { "type": "uniform" },
      "on": "shear"
    }
  ]
}
{
  "version": 1,
  "entity": "minecraft:pig",
  "drops": [
    {
      "item": "minecraft:carrot",
      "chance": 1,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "on": "hit",
      "cooldown": 40
    }
  ]
}
{
  "version": 1,
  "entity": "minecraft:chicken",
  "drops": [
    {
      "item": "minecraft:gold_nugget",
      "chance": 1,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "on": "periodic",
      "interval": 1200
    }
  ]
}

Timing

  • periodic: the first drop comes one interval after the timer starts, then every interval.
  • hit: the first hit can drop, then the drop waits cooldown ticks.
  • The timer restarts on every attempt, whether the chance succeeded or not.
  • Timers are saved with the mob and survive unloading and portals.
  • interval must be at least 1, cooldown at least 0. The key of the other trigger is ignored with a warning.

Details per trigger

shear
Any mob that can be sheared right now (sheep with wool, snow golems, mooshrooms, modded shearable mobs). Dispensers shear without a player, so they never trigger it.
hit
Needs real damage after armor, Resistance and absorption: a hit fully blocked by Resistance V does not drop. Fake players of machines count as players here.
lightning
Once per bolt, even though a bolt lasts several ticks. The bolt that made the drop does not destroy it (fire on the ground can still burn it, as with any item).
periodic
Only living mobs in loaded chunks.

Drops of other triggers spawn at the mob, and experience drops spawn experience orbs there.

Loot conditions on triggers

Drops of other triggers use the death loot context with a stand-in damage source: the player's attack for shear and hit (so killed_by_player passes for that player), lightning for lightning, generic damage for periodic.

Removal files and triggers

A removal file has an optional top-level on (default death) and only removes drops of that trigger. On non-death triggers it removes only Alkahest Drops drops of other namespaces; the game's own drops (sheep wool, chicken eggs) are never touched. A top-level on in a drop file is ignored with a warning: set it per drop.

For example, if another datapack or a mod makes sheep drop string when sheared, this file in your own namespace removes it. Sheep still drop their string on death, and the wool the game drops when shearing stays.

{
  "version": 1,
  "entity": "minecraft:sheep",
  "on": "shear",
  "removals": [ "minecraft:string" ]
}

Testing triggers

/alkdrops simulate entity minecraft:sheep on shear 100
/alkdrops simulate entity minecraft:pig on hit 50
/alkdrops simulate entity minecraft:chicken on periodic 24000

With on periodic the number is ticks, and rates are shown per minute. Each simulated hit deals 1 damage.
