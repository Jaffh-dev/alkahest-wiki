Drop actions

on_drop does something when a drop lands: make the item glow through walls, or run a datapack function at the item. Functions can play sounds, show particles, announce the drop, reward or punish players.

Keys

"on_drop": { "glow": true, "run_function": "mypack:legendary_drop" }
glowbooleanOptional

The item gets the glowing outline, visible through walls. Saved with the item.

run_functionfunction idOptional

A datapack function, such as mypack:legendary_drop for data/mypack/functions/legendary_drop.mcfunction. Function tags are not supported.

  • Both keys missing (or false): warning, nothing happens.
  • A malformed id is an error; a function no datapack defines is a warning (only the function is ignored).
  • On experience drops, on_drop is ignored with a warning.

How the function runs

  • It runs as the dropped item, at the item: @s is the item and ~ ~ ~ is where it landed.
  • It runs at the end of the tick the item spawned in, with permission level 2 and no chat output.
  • While it runs, the drop's player carries the tag alkahestdrops.drop_player, so @a[tag=alkahestdrops.drop_player] selects them. The tag is removed right after.
  • The drop's player is the killer, the shearer or hitter, the breaker, or the owner of a per-player drop. Machines' fake players are not tagged. Lightning, periodic and explosion drops have no player.
  • If the item is gone before the end of the tick (merged into another stack, killed), the function does not run.

Recipes

Legendary drop

Sound, totem particles, a chat message naming the player and the item, and an action bar title.

# Runs as the dropped item, at the item.
playsound minecraft:ui.toast.challenge_complete player @a ~ ~ ~ 1 1
particle minecraft:totem_of_undying ~ ~0.5 ~ 0.2 0.5 0.2 0.3 40
particle minecraft:dust 1 0.6 0 1.5 ~ ~1 ~ 0.1 1 0.1 0 30
tellraw @a ["",{"selector":"@a[tag=alkahestdrops.drop_player]","color":"gold"},{"text":" found a legendary ","color":"gold"},{"selector":"@s"}]
title @a[tag=alkahestdrops.drop_player] actionbar {"text":"Legendary drop!","color":"gold","bold":true}

Server announcement

tellraw @a ["",{"text":"[Drops] ","color":"aqua"},{"selector":"@a[tag=alkahestdrops.drop_player]"},{"text":" got "},{"selector":"@s","color":"yellow"},{"text":"!"}]

Colored particle column

particle minecraft:dust 0.4 0.2 1 2 ~ ~1 ~ 0.05 1.5 0.05 0 80 force
particle minecraft:end_rod ~ ~0.5 ~ 0 1 0 0.05 20 force
playsound minecraft:block.amethyst_block.chime block @a ~ ~ ~ 1 1.2

Punish nearby players

A cursed drop that hurts everyone close except the player who got it.

effect give @a[distance=..16,tag=!alkahestdrops.drop_player] minecraft:wither 5 1
particle minecraft:smoke ~ ~0.5 ~ 1 0.5 1 0.02 60
playsound minecraft:entity.wither.ambient hostile @a ~ ~ ~ 1 0.8

Reward the player

experience add @a[tag=alkahestdrops.drop_player] 50 points
effect give @a[tag=alkahestdrops.drop_player] minecraft:luck 600 0

Using it in a drop file

{
  "version": 1,
  "entity": "minecraft:rabbit",
  "drops": [
    {
      "item": "minecraft:diamond",
      "chance": 0.02,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "on_drop": { "glow": true, "run_function": "mypack:legendary_drop" }
    }
  ]
}
Limits
  • Actions happen only when the drop spawns as an item in the world. A grave mod that keeps the drops, or an auto-pickup mod that puts them straight into an inventory, skips them.
  • A function runs once. Effects that last until pickup would need a repeating function of your own.
  • simulate ... drop runs no actions. JEI does not show them.
