Getting started

Alkahest Drops reads JSON files from datapacks and changes what mobs and blocks drop. This page builds a working datapack in five minutes: a zombie that sometimes drops a diamond.

Requirements

Minecraft 1.20.1 with Forge 47.4 or newer, and Alkahest Drops installed on the server (in singleplayer, the game is the server). JEI is optional.

Folder layout

A datapack is a folder (or a zip) inside your world's datapacks folder. Alkahest Drops reads two folders inside each namespace:

  • data/<namespace>/mob_drops/: files about mobs.
  • data/<namespace>/block_drops/: files about blocks.

Subfolders are allowed. The file id is the namespace plus the path, such as mypack:zombie_diamond.

my_drops/
├── pack.mcmeta
└── data/
    └── mypack/
        ├── mob_drops/
        │   └── zombie_diamond.json
        └── block_drops/
            └── stone_flint.json

pack.mcmeta

Minecraft 1.20.1 uses pack format 15.

{
  "pack": {
    "pack_format": 15,
    "description": "My drops"
  }
}

A first drop file

This file gives zombies a 2% chance to drop one diamond. Every key shown here is required: Alkahest Drops has no hidden defaults, so a file always says exactly what it does. 

{
  "version": 1,
  "entity": "minecraft:zombie",
  "drops": [
    {
      "item": "minecraft:diamond",
      "chance": 0.02,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" }
    }
  ]
}
version
The file format version. Always 1 for now.
entity
Which mob the file is about. Block files use block instead.
drops
The drops to add. Each one needs item, chance (0 to 1), count and drop_behavior.

The same idea for a block: stone gets a 10% chance of 1 to 2 flint.

{
  "version": 1,
  "block": "minecraft:stone",
  "drops": [
    {
      "item": "minecraft:flint",
      "chance": 0.1,
      "count": { "min": 1, "max": 2 },
      "drop_behavior": { "type": "uniform" }
    }
  ]
}

Drops added to a mob or block come on top of its normal loot. To take something away, use a removal file.

Load and check it

  1. Put the folder in saves/<world>/datapacks/ (or world/datapacks/ on a server).
  2. Run /reload in game. Alkahest Drops reads every file again.
  3. Run /alkdrops validate. It lists every error and warning found in the files; a clean pack shows none. Problems are also written to the server log.
  4. Run /alkdrops simulate entity minecraft:zombie 1000 to roll 1000 zombie kills without killing anything. About 20 diamonds should show up.
/reload
/alkdrops validate
/alkdrops simulate entity minecraft:zombie 1000
A broken file never crashes the game

A file with an error is skipped (or only the bad drop is skipped) and the problem is reported. Everything else keeps working. See Validation and limits.
