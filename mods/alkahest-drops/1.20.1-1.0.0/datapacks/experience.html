Experience drops

A drop can give experience instead of an item. A removal entry can take experience away. Together they set the experience of any mob or block.

Adding experience

Write "experience": true instead of item. count is the amount of experience.

{
  "version": 1,
  "block": "minecraft:stone",
  "drops": [
    {
      "experience": true,
      "chance": 1,
      "count": { "min": 1, "max": 3 },
      "drop_behavior": { "type": "uniform" },
      "enchant_bonus": [
        { "enchant": "minecraft:fortune",
          "on_enchant": { "bonus_count": { "bonus_max_per_level": 1 } } }
      ]
    }
  ]
}

An experience drop uses chance, count, drop_behavior, enchant_bonus and local conditions. nbt, functions and on_drop are ignored with a warning. Writing both item and "experience": true is an error.

When experience drops

As in vanilla:

  • Mobs: only when a player kills them.
  • Blocks: only when a player breaks them with a tool that can harvest them; never from explosions or in creative mode.
  • Silk Touch does not stop experience by itself. Add a condition if you want that.
  • On other triggers (shear, hit, lightning, periodic), experience orbs spawn at the mob.

Removing experience

{
  "version": 1,
  "block": "minecraft:diamond_ore",
  "removals": [ { "experience": true } ]
}

This removes the vanilla experience and the experience drops of other namespaces. Like item removals, it never touches the drops of its own namespace. Item entries (even "*") never remove experience.

Setting experience to an exact amount

A removal file and a drop file in the same namespace: the removal clears vanilla experience, the drop adds yours.

{
  "version": 1,
  "entity": "minecraft:cow",
  "removals": [ { "experience": true } ]
}
{
  "version": 1,
  "entity": "minecraft:cow",
  "drops": [
    {
      "experience": true,
      "chance": 1,
      "count": { "min": 10, "max": 10 },
      "drop_behavior": { "type": "uniform" },
      "enchant_bonus": [
        { "enchant": "minecraft:looting",
          "on_enchant": { "bonus_count": { "bonus_min_per_level": 5, "bonus_max_per_level": 5 } } }
      ]
    }
  ]
}

Cows now give exactly 10 experience, plus 5 per Looting level.

Conditional experience removal

{
  "version": 1,
  "entity": "*",
  "removals": [
    { "experience": true,
      "conditions": [
        { "condition": "minecraft:entity_properties", "entity": "killer",
          "predicate": { "flags": { "is_sneaking": true } } }
      ] }
  ]
}
Ender Dragon

The Ender Dragon gives its experience in its own way, outside the event Alkahest Drops uses, so its vanilla experience cannot be removed.
