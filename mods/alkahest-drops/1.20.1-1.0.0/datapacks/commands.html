Commands

/alkdrops checks and tests your files in game. All subcommands need permission level 2 (operators, or cheats on in singleplayer). /alkdrops help explains each one in game.

CommandUse it to
validateList errors and warnings of the loaded files.
filesSee which files loaded, per namespace.
sourcesFind which files add or remove an item or experience.
dropsSee everything that applies to one mob or block.
simulateRoll drops many times without killing anything.
resetClear a player's pity and first-drop progress.
helpExplain the commands in chat.

Long outputs are split into pages with clickable arrows; every command takes page <n> at the end. File ids in the output can be clicked to copy their path.

validate

/alkdrops validate [errors | warnings] [namespace] [page <n>]

Lists the problems the last /reload found. Errors mean a file, drop or entry was skipped; warnings mean a value was clamped or ignored and the rest still loads.

/alkdrops validate
/alkdrops validate errors
/alkdrops validate warnings mypack

files

/alkdrops files [namespace] [page <n>]

Without a namespace: how many drop and removal files each namespace has, for mobs and blocks. With one: each file with its kind, target and size, and which ones were skipped.

sources

/alkdrops sources <item | experience> [page <n>]

Every file that adds the item (or experience) and every file that removes it. Handy for "where does this drop come from?".

/alkdrops sources minecraft:rotten_flesh
/alkdrops sources experience

drops

/alkdrops drops <entity | block> [page <n>]

Every drop and removal that applies to a mob or block, from files naming it by id, mod:*, #tag or *. An id that is both a mob and a block (such as minecraft:tnt) shows both.

simulate

Rolls the vanilla loot table and the Alkahest Drops rules many times and reports what dropped: total, average per run, and percent of runs. Nothing is killed or broken.

/alkdrops simulate entity <entity> [on <trigger>] [runs] [enchant <enchantments>] [by player | none | <killer>] [sneaking] [burning] [only <experience | filter>] [drop [no-text]]
/alkdrops simulate block <block> [runs] [enchant <enchantments>] [by player | none | explosion] [sneaking] [only <experience | filter>] [drop [no-text]]

Options are optional but must come in this order.

on <trigger>
Mobs: death (default), shear, hit, lightning, periodic. Other triggers roll only Alkahest Drops drops. Each simulated hit deals 1 damage. With periodic, the number is ticks and rates are per minute.
runs
1 to 1,000,000; 1 when missing.
enchant <enchantments>
Forced enchantments in item NBT format: [{id:"minecraft:looting",lvl:3}], levels 0 to 255. They replace those levels on the held item (on the tool for blocks); level 0 removes one. Not allowed on lightning or periodic.
by
player: a copy of you with your equipment (default for players; a blank player from the console). none: no player (generic damage for mobs, a netherite pickaxe for blocks), no experience. A mob type: that mob is the killer. explosion: blocks only, a TNT explosion.
sneaking, burning
The actor crouches; the mob dies on fire (mobs only).
only <experience | filter>
Show only experience, or only items matching an id, #tag or NBT. Every run is still rolled in full.
drop [no-text]
Also spawns what the report shows at your position. no-text does it silently, for datapack functions.

Simulations use their own fake player, never your real pity or first-drop progress; pity and one-time drops are reported on their own lines. /alkdrops simulate page <n> shows another page of the last report without rolling again.

reset

/alkdrops reset <player> [first | pity] [entities | blocks | <entity | block>]

Clears drop progress so first drops drop again and pity counters start over. Without first or pity, both are cleared. Drops of tag, mod:* and * files are reset for every mob or block they match.

/alkdrops reset @s
/alkdrops reset Steve first
/alkdrops reset @a pity blocks
/alkdrops reset @s minecraft:horse
