JEI and multiplayer

Alkahest Drops runs on the server. JEI is optional: with it, players see a page for every mob and block with everything it drops.

Who needs what

SetupDrops workJEI pages
Singleplayer with Alkahest DropsYesWith JEI installed
Server with Alkahest Drops, player with Alkahest Drops and JEIYesYes
Server with Alkahest Drops, Forge player without itYesNo

Drops, commands and checks all happen on the server. Players only need the mod (with JEI) to see the JEI pages.

What JEI shows

  • A page for every mob that can die and every block that drops something, with its full loot: the vanilla loot table, vanilla experience, and Alkahest Drops drops and removals.
  • One page per trigger of a mob: death first, then shear, hit, lightning, periodic. Non-death pages show only Alkahest Drops drops.
  • Each drop's tooltip: chance, count, rolls, and icons for enchantment bonuses, conditions, pity, first drop and per player. Hold Shift for details, such as each enchantment's bonus.
  • Mobs are JEI ingredients: look up what a mob drops, or which mobs drop an item.
  • The pages refresh after every /reload.

Cost

The JEI data is built once per datapack load on the server and sent only to players who have the mod and JEI. Without JEI there is no network traffic and no client cost.

What JEI cannot show
  • Drops other mods add in code (global loot modifiers, drop events): only loot table files are read.
  • Complex loot tables (alternatives, nested tables) are shown approximately.
  • Conditions that cannot be described are summed up as "has hidden conditions".
  • on_drop actions.
