Enchantment bonuses

enchant_bonus makes a drop better with an enchantment on the held item: Looting, Fortune, or any other enchantment, modded ones included. Each enchantment can raise the chance, the count and the rolls.

Example

{
  "version": 1,
  "entity": "minecraft:zombie",
  "drops": [
    {
      "item": "minecraft:diamond",
      "chance": 0.02,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "enchant_bonus": [
        { "enchant": "minecraft:looting",
          "on_enchant": {
            "bonus_chance": { "bonus_chance_per_level": 0.01, "max_bonus_chance": 0.03 }
          } },
        { "enchant": "minecraft:sharpness",
          "on_enchant": {
            "bonus_count": { "bonus_max_per_level": 1, "max_bonus_max": 2 }
          } }
      ]
    }
  ]
}

With Looting III and Sharpness V: chance 2% + 3% = 5%, and the count range becomes 1 to 3 (max raised by 1 per Sharpness level, capped at +2).

Where the level comes from

Always from the item in the player's (or killer's) hand when the drop happens:

DropItem read
Mob deathThe killer's main-hand weapon. Looting also follows other mods that change the Looting level.
"on": "hit"The player's main-hand weapon.
"on": "shear"The shears.
Block breakThe tool.
lightning, periodicNothing: no bonus (a warning if the file has one).

Entry keys

enchantenchantment idRequired

Such as minecraft:looting. An enchantment of a mod that is not installed skips only that entry, with a warning. The same enchantment twice in one drop is an error.

on_enchantobjectRequired

One or more of bonus_chance, bonus_roll, bonus_count. Empty is an error.

How bonuses are computed

For each key: bonus = per-level value × enchantment level, then capped by its max_* key. The cap limits the bonus, not the total. Bonuses of several enchantments add up; a chance never goes above 1.

A max_* key is optional, but needs its per-level key. Missing, it means "no cap" (up to the server limit).

Drops that need the enchantment

Some values are allowed at 0 only when a bonus raises them, so the drop happens only with the enchantment:

  • "chance": 0 needs a bonus_chance in some entry.
  • count 0 to 0 needs bonuses that raise both min and max (they may come from different enchantments).
  • rolls, chance_per_roll or increment_value at 0 need the matching bonus_roll key.
{
  "item": "minecraft:nether_star",
  "chance": 0,
  "count": { "min": 1, "max": 1 },
  "drop_behavior": { "type": "uniform" },
  "enchant_bonus": [
    { "enchant": "minecraft:looting",
      "on_enchant": { "bonus_chance": { "bonus_chance_per_level": 0.001 } } }
  ]
}
Bonuses that stack with loot functions

If functions has minecraft:looting_enchant or minecraft:apply_bonus for the same enchantment as an enchant_bonus entry, both apply. Alkahest Drops warns about it.
