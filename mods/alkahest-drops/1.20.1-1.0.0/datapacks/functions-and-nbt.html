Loot functions and NBT

nbt sets item data directly. functions runs vanilla loot functions on the dropped stack: names, enchantments, smelting, and anything other mods register.

nbt

Item NBT, written in one of two ways.

SNBT text

The same format as /give, inside a JSON string. Quotes inside it are escaped with \".

{
  "item": "minecraft:diamond_sword",
  "chance": 0.01,
  "count": { "min": 1, "max": 1 },
  "drop_behavior": { "type": "uniform" },
  "nbt": "{display:{Name:'{\"text\":\"Zombie Slayer\",\"color\":\"gold\"}'},Damage:100}"
}

JSON object

A plain JSON object is read as NBT too, which avoids most of the escaping:

{
  "item": "minecraft:diamond_sword",
  "chance": 0.01,
  "count": { "min": 1, "max": 1 },
  "drop_behavior": { "type": "uniform" },
  "nbt": { "display": { "Name": "{\"text\":\"Zombie Slayer\",\"color\":\"gold\"}" }, "Damage": 100 }
}
SNBT and JSON do not give the same item

JSON has no NBT number types: whole numbers become ints, decimals become doubles, and true / false become bytes. SNBT can say exactly which type it wants (1b, 1s, 1.5f). So {Unbreakable:1b} in SNBT and {"Unbreakable": 1} in JSON make items with different NBT, which do not stack with each other or with items made by /give. When the item must match others exactly, use SNBT with the types the game uses.

Invalid NBT is an error and the drop is skipped.

functions

An array of loot functions, in the same format as loot tables. They run in order, after the count and nbt are applied. Functions can have their own conditions.

{
  "version": 1,
  "block": "minecraft:copper_ore",
  "drops": [
    {
      "item": "minecraft:raw_copper",
      "chance": 1,
      "count": { "min": 2, "max": 2 },
      "drop_behavior": { "type": "uniform" },
      "functions": [
        { "function": "minecraft:furnace_smelt",
          "conditions": [
            { "condition": "minecraft:match_tool", "predicate": { "items": [ "minecraft:diamond_pickaxe" ] } }
          ] }
      ]
    },
    {
      "item": "minecraft:book",
      "chance": 0.05,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "functions": [
        { "function": "minecraft:enchant_with_levels", "levels": 30, "treasure": false },
        { "function": "minecraft:set_name", "name": { "text": "Copper Tome", "color": "gold", "italic": false } }
      ]
    }
  ]
}

Raw copper comes out smelted with a diamond pickaxe, and a rare enchanted book named "Copper Tome" can drop.

Useful functions

FunctionEffect
minecraft:enchant_randomlyOne random enchantment.
minecraft:enchant_with_levelsEnchants as an enchanting table would at that level.
minecraft:set_name, set_loreName and lore.
minecraft:furnace_smeltSmelts the item; with an entity_properties fire condition, "cooked when the mob burns".
minecraft:set_damageTool durability.
minecraft:set_nbtMerges NBT.

Rules and warnings

  • An invalid function is an error: the drop is skipped.
  • A function that empties the stack drops nothing.
  • Removal files match the drop's item, not what a function turns it into.
  • A function or its condition that reads loot data Alkahest Drops never provides gets a warning.
  • minecraft:set_count without "add": true replaces the rolled count: warning.
  • looting_enchant or apply_bonus for an enchantment that is also in the drop's enchant_bonus gives both bonuses: warning.
  • On experience drops, nbt and functions are ignored with a warning.
