Known limits

Things Alkahest Drops does not do in this version, so you do not spend time looking for a bug.

Block drops

  • Blocks drop only when broken with a tool that can harvest them, as in vanilla, Alkahest Drops drops included.
  • Blocks with no loot table (such as a piston head) get Alkahest Drops drops only when a player breaks them.
  • Drops a block creates in its own code, outside its loot table, cannot be removed.
  • Experience from blocks needs a player with a harvesting tool: never from explosions or in creative mode.

Mob drops

  • The Ender Dragon's vanilla experience cannot be removed.
  • simulate does not show equipment drops, or drops other mods add during the drop event.

Triggers

  • Dispensers shear without a player, so they never trigger shear drops.
  • A mob whose own click action uses up the click before the shears would still count as sheared (no vanilla mob does this).
  • Removal files on non-death triggers cannot remove the game's own drops of those actions (sheep wool, chicken eggs).
  • simulate ... on shear does not show the game's own shear drops (wool).

Drop actions

  • on_drop and OnDropEvent happen only when the drop spawns as an item in the world: a grave mod or an auto-pickup mod skips them.
  • Experience drops have no actions.
  • A function runs once; there is no "repeat until picked up".
  • Function tags are not supported in run_function.

JEI

  • Drops other mods add in code (global loot modifiers, drop events) are not shown.
  • Complex vanilla loot tables are shown approximately.

Progress

  • Disabling a datapack and reloading cleans up its players' pity and first-drop progress.
  • Pity and first drops without an id are keyed by the drop's position in the file.

Validation

  • Count bonuses are only checked one by one. If bonus_min_per_level grows faster than bonus_max_per_level, a high enchantment level can push count.min above count.max. For example, a count of 1 to 2 with +2 min per Looting level becomes 7 to 2 at Looting III. The file still loads without a warning, and the drop then gives count.min (7) with uniform and the scaled behaviors, or count.max (2) with fixed_rolls and chained_rolls. Give bonus_max_per_level at least the same value as bonus_min_per_level to avoid it.
