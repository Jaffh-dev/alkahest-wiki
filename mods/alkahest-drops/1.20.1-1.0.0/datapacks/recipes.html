Recipes

Copy a file, change the ids and numbers, run /reload. Paths assume the namespace mypack.

Replace a drop

Skeletons drop 1 to 3 arrows with a guaranteed bone, instead of their usual arrows. A removal and a drop file in the same namespace (the removal never touches its own namespace's drops).

{
  "version": 1,
  "entity": "minecraft:skeleton",
  "removals": [ "minecraft:arrow" ]
}
{
  "version": 1,
  "entity": "minecraft:skeleton",
  "drops": [
    { "item": "minecraft:arrow", "chance": 1, "count": { "min": 1, "max": 3 }, "drop_behavior": { "type": "uniform" } },
    { "item": "minecraft:bone", "chance": 1, "count": { "min": 1, "max": 1 }, "drop_behavior": { "type": "uniform" } }
  ]
}

Rare drop with pity

Endermen: 0.5% for a totem, +0.25% per Looting level (up to +0.75%), guaranteed by the 200th kill without one.

{
  "version": 1,
  "entity": "minecraft:enderman",
  "drops": [
    {
      "item": "minecraft:totem_of_undying",
      "chance": 0.005,
      "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" },
      "enchant_bonus": [
        { "enchant": "minecraft:looting",
          "on_enchant": { "bonus_chance": { "bonus_chance_per_level": 0.0025, "max_bonus_chance": 0.0075 } } }
      ],
      "id": "totem",
      "pity": 200,
      "on_drop": { "glow": true }
    }
  ]
}

Drop only for real players

Mob farms with machine "fake players" get nothing from this file.

{
  "version": 1,
  "entity": "minecraft:blaze",
  "conditions": [ { "condition": "alkahestdrops:killed_by_real_player" } ],
  "drops": [
    { "item": "minecraft:magma_cream", "chance": 0.25, "count": { "min": 1, "max": 2 }, "drop_behavior": { "type": "uniform" } }
  ]
}

Shear drop

Shearing a mooshroom has a 5% chance of a golden apple.

{
  "version": 1,
  "entity": "minecraft:mooshroom",
  "drops": [
    { "item": "minecraft:golden_apple", "chance": 0.05, "count": { "min": 1, "max": 1 },
      "drop_behavior": { "type": "uniform" }, "on": "shear" }
  ]
}

Boss loot that scales with health

Every hostile mob of a tag drops emeralds by its max health: about 2 for a zombie, 10 for a wither.

{
  "version": 1,
  "entity": "#mypack:hostile",
  "conditions": [ { "condition": "minecraft:killed_by_player" } ],
  "drops": [
    { "item": "minecraft:emerald", "chance": 1, "count": { "min": 1, "max": 16 },
      "drop_behavior": { "type": "max_health", "function": "log", "multiplier": 3, "divisor": 10 } }
  ]
}

The tag itself goes in data/mypack/tags/entity_types/hostile.json.

No drops unless a player kills

Every mob drops no items unless a player killed it (without a player kill, mobs give no experience anyway). Players are never targeted by *.

{
  "version": 1,
  "entity": "*",
  "conditions": [
    { "condition": "minecraft:inverted", "term": { "condition": "minecraft:killed_by_player" } }
  ],
  "removals": [ "*" ]
}

Ore bonus with Fortune

Diamond ore has a 2% chance of an emerald, and Fortune adds rolls.

{
  "version": 1,
  "block": "minecraft:diamond_ore",
  "drops": [
    {
      "item": "minecraft:emerald",
      "chance": 0.02,
      "count": { "min": 1, "max": 4 },
      "drop_behavior": { "type": "fixed_rolls", "rolls": 1, "chance_per_roll": 0.5, "increment_value": 1 },
      "enchant_bonus": [
        { "enchant": "minecraft:fortune",
          "on_enchant": { "bonus_roll": { "bonus_rolls_per_level": 1, "max_bonus_rolls": 3 } } }
      ]
    }
  ]
}
