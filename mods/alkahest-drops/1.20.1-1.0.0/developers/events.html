Events

Two Forge events in com.jaffh.alkahestdrops.api.event, both on MinecraftForge.EVENT_BUS and fired on the server thread.

OnDropEvent

Fired when an item rolled by a drop file has spawned in the world, for every drop file item drop, whether or not the file has on_drop. It fires at the end of the tick the item spawned in, so the item is already in the level.

MethodReturns
getItem()The ItemEntity, in the level. Never null.
getOrigin()DropOrigin.Mob(mob) or DropOrigin.Block(state, pos).
getDropKey()Stable key of the drop: "mob:mypack:dragon@legendary_scale" with an id, else "mob:<file id>#<index>".
getTrigger()The DropTrigger; always DEATH for blocks.
getPlayer()The killer, shearer, hitter, breaker or per-player owner; null without a player. Fake players included.
  • Cancelable. Cancelling skips the drop's run_function. The item still exists, and the glow (if any) is already applied.
  • Order: the item spawns, the glow is applied, the event fires, then run_function runs.
  • Never fired for experience drops, simulations, or stacks that never spawned as an item (a grave mod that keeps the drops, an auto-pickup mod).

Example: announce rare drops

public final class RareDropAnnouncer {
    private RareDropAnnouncer() {}

    public static void register() {
        MinecraftForge.EVENT_BUS.addListener(RareDropAnnouncer::onDrop);
    }

    private static void onDrop(OnDropEvent event) {
        if (!event.getDropKey().endsWith("@legendary_scale")) return;
        Player player = event.getPlayer();
        if (player == null || player instanceof FakePlayer) return;

        ItemStack stack = event.getItem().getItem();
        player.getServer().getPlayerList().broadcastSystemMessage(
                Component.literal(player.getScoreboardName() + " found ").append(stack.getHoverName()), false);
    }
}

DropFilesLoadedEvent

Fired once the drop and removal files are loaded and ready to read: when the server has started, and at the end of every /reload. Tags, the server config and the files are all in place by then. Player joins do not fire it.

MethodReturns
getServer()The MinecraftServer whose files were loaded.

Rebuild anything you cached from the read API here.

private static void onFilesLoaded(DropFilesLoadedEvent event) {
    ZOMBIE_DROPS = AlkahestDropsApi.getMobDrops(EntityType.ZOMBIE, DropTrigger.DEATH);
}

Coming in API 1.1

Mods will be able to register their own on_drop action types that pack authors use by id ("actions": [ { "type": "mymod:meteor_strike", "radius": 3 } ]). The design is final, so the file format will not need a version 2 for it.
