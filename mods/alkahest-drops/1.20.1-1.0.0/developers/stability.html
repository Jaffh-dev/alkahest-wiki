Stability and stable ids

What you can rely on when you depend on Alkahest Drops.

The API promise

Everything in com.jaffh.alkahestdrops.api and its subpackages follows semantic versioning:

  • No breaking change within a major version. Code built against API 1.0 works with every 1.x.
  • Deprecation before removal. Anything removed is deprecated for at least one minor version first.
  • @since on everything. Each type and method says which version added it.
  • Internal means internal. Classes outside api may change in any release; do not depend on them.

Parameters are non-null unless marked @Nullable.

Version numbers

A release is named <minecraft>-<major>.<minor>.<patch>, such as 1.20.1-1.0.0. The API version (1.0.0 in this release) is listed in each release's changelog.

File format versions

Every file declares "version": 1. A future format would be version 2, and the mod would keep reading version 1 files.
