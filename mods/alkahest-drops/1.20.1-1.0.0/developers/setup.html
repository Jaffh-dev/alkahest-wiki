Depending on the API

To use the events or the API, add Alkahest Drops as an optional dependency and keep the code that touches it in one class that only loads when the mod is present.

Gradle (ForgeGradle 6)

Alkahest Drops is on the Modrinth Maven. Add the repository and the dependency:

repositories {
    exclusiveContent {
        forRepository {
            maven {
                name = "Modrinth"
                url = "https://api.modrinth.com/maven"
            }
        }
        filter {
            includeGroup "maven.modrinth"
        }
    }
}

dependencies {
    // Compile against the API without making it required.
    compileOnly fg.deobf("maven.modrinth:alkahest-drops:1.20.1-1.0.0")
    // Also load it in your dev runs, to test the integration.
    runtimeOnly fg.deobf("maven.modrinth:alkahest-drops:1.20.1-1.0.0")
}

fg.deobf remaps the jar to your development mappings. Change the version to match the release you target; all 1.x versions keep the API compatible.

Without the Maven

To build against a jar you downloaded, put it in a libs folder next to build.gradle:

repositories {
    flatDir {
        dir 'libs'
    }
}

dependencies {
    compileOnly fg.deobf("blank:alkahestdrops:1.20.1-1.0.0")
    runtimeOnly fg.deobf("blank:alkahestdrops:1.20.1-1.0.0")
}

With a flat directory the group is ignored: alkahestdrops:1.20.1-1.0.0 resolves to libs/alkahestdrops-1.20.1-1.0.0.jar.

mods.toml

Declare it as optional so Forge checks the version when it is present but never requires it.

[[dependencies.mymod]]
    modId = "alkahestdrops"
    mandatory = false
    versionRange = "[1.20.1-1.0.0,)"
    ordering = "NONE"
    side = "BOTH"

Keep it isolated

Classes that import com.jaffh.alkahestdrops must only load when the mod is installed. Put them in a compat/alkahestdrops package and reach them through a check of the mod list.

@Mod(MyMod.MODID)
public final class MyMod {
    public static final String MODID = "mymod";

    public MyMod() {
        if (ModList.get().isLoaded("alkahestdrops")) {
            AlkahestDropsCompat.register();
        }
    }
}
public final class AlkahestDropsCompat {
    private AlkahestDropsCompat() {}

    public static void register() {
        MinecraftForge.EVENT_BUS.addListener(AlkahestDropsCompat::onDrop);
    }

    private static void onDrop(OnDropEvent event) {
        // Only runs when Alkahest Drops is installed.
    }
}

Never mention an Alkahest Drops class in a field, method signature or annotation of a class that always loads (such as your main class), and never use @Mod.EventBusSubscriber on the compat class: Forge would load it even without Alkahest Drops.

Requirements

  • Minecraft 1.20.1, Forge 47.4 or newer, Java 17.
  • Official (Mojang) mappings in the examples; the API uses vanilla types such as EntityType, Block, Player and ItemEntity.
