Read API

Read what the loaded drop and removal files do to a mob or block: for wiki mods, quest mods, recipe viewers and server tools.

Methods

TargetDrops AlkahestDropsApi.getMobDrops(EntityType<?> type, DropTrigger trigger)
TargetDrops AlkahestDropsApi.getBlockDrops(Block block)
  • Files that name the target by id, tag, mod:* or * are all included.
  • Server thread only. Any other thread throws IllegalStateException.
  • Returns TargetDrops.EMPTY when no server is running or before the files are loaded.
  • Built on each call (it is not meant for every tick). Cache results and refresh them on DropFilesLoadedEvent.

TargetDrops

MemberMeaning
drops()List<AddedDrop>: drops the files add, without those that removal files of other namespaces always remove (as in game). Immutable.
removals()List<DropRemoval>: removal entries that apply, conditional or not. Immutable.
isEmpty()True when nothing is added or removed.
EMPTYConstant with no drops and no removals.

Conditional removals are not applied to drops(); they are listed in removals().

AddedDrop

ComponentTypeMeaning
fileIdResourceLocationDrop file id, such as mypack:zombie.
dropKeyStringSame key as OnDropEvent.getDropKey() and the progress API.
item@Nullable ItemDropped item; null for experience.
chancedoubleBase chance 0–1, before enchantment bonuses.
minCount, maxCountintBase count range (or experience). Roll-based and scaled behaviors may give other amounts.
triggerDropTriggerWhat makes it drop.
isConditionalbooleanLoot conditions (file or drop) decide whether it drops.
hasEnchantBonusbooleanAn enchantment raises chance, count or rolls.
pityintForced after that many misses; 0 for none.
isFirstDropbooleanfirst_kill / first_break.

isExperience() is true when item() is null.

DropRemoval

ComponentTypeMeaning
fileIdResourceLocationRemoval file id.
items@Nullable StringAs written: an item id, #tag or *; null for experience.
triggerDropTriggerTrigger whose drops it removes.
isConditionalbooleanLoot conditions decide whether it removes.

isExperience() is true when items() is null. removes(Item) tells whether the entry names the item, one of its tags (as bound now) or *.

DropTrigger

DEATH, SHEAR, HIT, LIGHTNING, PERIODIC. Blocks only use DEATH (a break).

  • id(): the id as written in files, such as "shear".
  • fromId(String): Optional<DropTrigger>.
  • hasPlayer(): true for death, shear and hit.

Example: list zombie drops in a command

TargetDrops drops = AlkahestDropsApi.getMobDrops(EntityType.ZOMBIE, DropTrigger.DEATH);
for (AddedDrop drop : drops.drops()) {
    String what = drop.isExperience() ? "experience" : String.valueOf(ForgeRegistries.ITEMS.getKey(drop.item()));
    source.sendSystemMessage(Component.literal(
            what + " " + Math.round(drop.chance() * 100) + "% x" + drop.minCount() + "-" + drop.maxCount()));
}
boolean noFlesh = drops.removals().stream()
        .anyMatch(removal -> !removal.isConditional() && removal.removes(Items.ROTTEN_FLESH));
Client side

The read API works on the server (singleplayer included). A client-side read API for recipe viewers on multiplayer servers may come in a 1.x version.
