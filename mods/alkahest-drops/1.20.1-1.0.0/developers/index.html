For mod developers

Alkahest Drops can be used at three levels. Start with the first: most mods never need more.

1. Ship drop files Put mob_drops/ and block_drops/ files in your mod's resources. No dependency, no code; ignored when Alkahest Drops is absent. 2. Listen to events OnDropEvent when a drop spawns, DropFilesLoadedEvent after every reload. Optional dependency. 3. Use the API Read what files do to a mob or block, read and reset a player's pity and first drops.

What the API contains

Everything public lives in com.jaffh.alkahestdrops.api and follows semantic versioning from 1.0.0. Classes outside api are internal and may change in any release.

TypePackagePurpose
AlkahestDropsApiapiStatic entry point: read drops, read and reset progress.
TargetDrops, AddedDrop, DropRemovalapiWhat drop and removal files do to one target.
DropTriggerapideath, shear, hit, lightning, periodic.
DropOriginapiSealed: Mob(mob) or Block(state, pos).
OnDropEventapi.eventA drop file item spawned (cancelable).
DropFilesLoadedEventapi.eventFiles loaded or reloaded.

Facts worth knowing

  • Server side. Drops, commands and checks run on the server. Forge clients without the mod can join; players need the mod (with JEI) only to see JEI pages.
  • No mixins. Mob drops use Forge's drop and experience events, block drops a global loot modifier.
  • JEI is optional and costs nothing when absent: no network channel traffic, no client work.
  • A broken file never crashes a server. Errors skip the smallest part (file, drop or entry) and are reported with their JSON path.
  • Loot conditions and functions of any mod work inside drop files, so your own registered conditions are usable by pack authors.
  • Small footprint. Measured with spark: about 0.75 MB of heap for the loaded rules and the JEI summary, no visible cost during gameplay.
  • Tested alongside Twilight Forest, L_Ender's Cataclysm, Alex's Mobs, Biomes O' Plenty, Mekanism and Farmer's Delight.

Versions

Mod versions read <minecraft>-<major>.<minor>.<patch>, such as 1.20.1-1.0.0. This version ships API 1.0.0 for Minecraft 1.20.1 on Forge 47.4 or newer. See Stability and stable ids.

Answering bug reports

When a player reports a strange drop from your mob or block, ask them to run /alkdrops drops <id> or /alkdrops sources <item>. The output names every Alkahest Drops file that adds or removes something, so you know right away whether a datapack is involved.
